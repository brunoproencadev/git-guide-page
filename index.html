Guia Básico e Prático de Git

O Git é um sistema de controle de versão distribuído essencial para o desenvolvimento de software. Confira os comandos mais utilizados no dia a dia:

1. Configuração Inicial

Configure seu nome e email antes de começar a fazer commits:

git config --global user.name "Seu Nome"
git config --global user.email "seu.email@exemplo.com"

2. Criando ou Clonando Repositórios

Inicie um repositório local ou clone um projeto existente:

# Iniciar repositório na pasta atual
git init

# Clonar repositório remoto
git clone https://github.com/usuario/repositorio.git

3. Ciclo de Trabalho Básico

Verifique alterações, adicione ao stage e crie um commit:

# Ver status dos arquivos alterados
git status

# Adicionar arquivos específicos ou todos
git add nome-do-arquivo.extensao
git add .

# Gravar alterações com uma mensagem descritiva
git commit -m "Mensagem descrevendo a alteração"

4. Sincronizando com Repositório Remoto

Envie ou puxe atualizações do GitHub/remoto:

# Conectar repositório local a um remoto
git remote add origin https://github.com/usuario/repositorio.git

# Enviar alterações (ramo main)
git push -u origin main

# Puxar atualizações mais recentes do remoto
git pull

5. Trabalhando com Branches (Ramificações)

Crie novas branches para desenvolver funcionalidades isoladas:

# Listar branches
git branch

# Criar e alternar para uma nova branch
git checkout -b feature-nova
# ou com versão moderna:
git switch -c feature-nova

# Voltar para a branch principal
git checkout main
# ou:
git switch main

# Mesclar alterações da branch para a branch atual
git merge feature-nova

6. Histórico e Logs

Visualize os commits anteriores:

# Histórico completo
git log

# Histórico resumido em uma linha por commit
git log --oneline
